# Finanzas Personales 2.0

Sube todos estos archivos y carpetas a la raíz del repositorio de GitHub Pages. Mantén la carpeta `assets/icons`. Después del despliegue abre la URL de Pages. En iPhone/iPad usa Safari > Compartir > Añadir a pantalla de inicio.

La versión 2.0 migra automáticamente los datos básicos de la versión simple si existen en el mismo navegador. Los perfiles nuevos se guardan por separado.
